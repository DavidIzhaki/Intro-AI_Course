    How to use

    Build a graph

    Pick a ready-made graph from Example, or build your own with the tools above the graph:

    ＋ Node: click on empty space.
    → Edge: click the source node, then the target node, and type the cost.
    h ✎: click a node to type its heuristic value (or double-click the green h=… label).
    Start / Goal: click a node. Delete: click a node or an edge.
    Double-click a node to rename it, or an edge to change its cost.
    Edit as text lets you type the whole graph (and all h values) as a list.

    Heuristic check computes the true cost-to-go h* and tells you whether h is goal-aware, safe, admissible and consistent. Tick h* to see h* on the graph (states with h > h* turn red).

    Run

    → step   ← back   Shift+→ next pop
    Space play / pause   End run to end   R reset

    Notes

    GBFS tests the goal on OPEN.min() just before popping it. UCS, A*, WA*, IDA*, Beam Search and Hill Climbing test it when a node is popped / taken.

    The frontier is ordered by the key of the algorithm (g, h or f). Equal keys are broken by Ties (FIFO = the node pushed first).

    Successors are generated left → right by their position in the drawing (or alphabetically). Hill Climbing breaks ties by taking the first one in this order.

    For IDA* the switch turns on the cycle check (“s' not on path”). Hill Climbing keeps no list at all.
