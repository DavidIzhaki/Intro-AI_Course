    How to use

    Build a graph

    Pick a ready-made graph from Example, or build your own with the tools above the graph:

    ＋ Node: click on empty space.
    → Edge: click the source node, then the target node, and type the cost.
    Start / Goal: click a node. Delete: click a node or an edge.
    Double-click a node to rename it, or an edge to change its cost.
    Edit as text lets you type the whole graph as an edge list.

    Run

    → step   ← back   Shift+→ next pop
    Space play / pause   End run to end   R reset

    Notes

    BFS and DFS test the goal when a node is generated. UCS and IDS test it when a node is popped.

    Successors are generated left → right by their position in the drawing (or alphabetically). DFS pushes them in this order, so the right-most one is popped first.

    Turn on the CLOSED list to see how duplicate detection stops the search from expanding the same state again and again (try “DFS cycle trap” and “Cycle, no solution”).
